## My projects

<section>
<h3><a href="https://github.com/Frolower/DiceDasher">DiceDasher</a></h3>
A web based virtual tabletop designed to support both system-agnostic and system-specific features, helping me run tabletop RPG sessions for my friends online.
<ul>
  <li>
    <strong>Design approach</strong>: The application follows a service-based architecture, allowing me to explore distributed system design and communication between services.
  </li>
  <li>
    <strong>Functionality</strong>: Users can create virtual rooms to play tabletop RPGs with friends. Support for multiple game systems and dedicated Game Master tools is currently in development.
  </li>
  <li>
    <strong>Challenges</strong>: Managing the project's scope, balancing development with other commitments, and learning new technologies and architectural concepts.
  </li>  
  <li>
    <strong>Tech stack</strong>: React, Go, net/http, PostgreSQL, gRPC
  </li>
</ul>
</section>

<section>
<h3><a href="https://github.com/Frolower/Orion-scheduling.git">Orion Scheduling</a></h3>
A web application that helps groups of friends find overlapping availability and coordinate meetings by sharing their schedules.
<ul>
  <li>
    <strong>Design approach</strong>: Focused on modularity and maintainability by organizing backend functionality into separate packages.
  <li>
    <strong>Functionality</strong>: The app allows users to create a timetable and share it with their friends to find overlaps in their free time.
  </li>
  <li>
    <strong>Challenges</strong>: Working within a tight deadline, learning a new backend technology stack, and making architectural decisions.
  </li>  
  <li>
    <strong>Tech stack</strong>: React, CSS, Node.js, Express, PostgreSQL
  </li>
</ul>
</section>
